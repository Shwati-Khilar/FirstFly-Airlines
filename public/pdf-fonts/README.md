# PDF fonts

These static TrueType fonts are embedded only in the downloaded PDF. They do not change the website's typography.

- Cormorant Garamond Regular: https://github.com/CatharsisFonts/Cormorant/tree/master/fonts/ttf
- DM Sans Regular: https://github.com/googlefonts/dm-fonts/tree/main/Sans/fonts/ttf

Both are distributed under the SIL Open Font License; corresponding license files are included here.
